# Blog Pessoal – Licóli Santos

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-blue)

Este projeto consiste em um **blog pessoal** desenvolvido como atividade prática da **Generation Brasil**, com foco na aplicação de **HTML5 semântico, CSS3 externo e JavaScript puro**, organização de arquivos e boas práticas de desenvolvimento front-end.

O blog apresenta minha trajetória profissional, transição de carreira para tecnologia e já conta com **funcionalidades interativas**, servindo como base sólida para evoluções futuras.

---

## 📌 Objetivo do Projeto

- Praticar a estruturação de páginas web com HTML5 semântico  
- Aplicar estilização utilizando CSS externo e organizado  
- Utilizar JavaScript puro para interações na interface  
- Trabalhar organização de pastas (assets) e versionamento com Git  
- Criar um projeto evolutivo, com foco em portfólio profissional

## 🧩 Funcionalidades Implementadas

- Página inicial com apresentação pessoal  
- Página “Sobre mim” com:
  - Foto de perfil  
  - Trajetória profissional  
  - Experiência e objetivos  
- Navegação entre páginas  
- Seção de tecnologias com layout em duas colunas  
- Seção de contato com:
  - Botões externos (LinkedIn, GitHub, WhatsApp e E-mail)
  - Botão **“Deixe sua mensagem”**
- **Modal de contato**:
  - Abertura sem redirecionamento de página  
  - Formulário com nome, e-mail e mensagem  
  - Mapa incorporado do Google Maps  
  - Fechamento automático após envio  
- Layout responsivo e visual consistente em todo o site
