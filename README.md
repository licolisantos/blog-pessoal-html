# Blog Pessoal – Licóli Santos

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-blue)

Este projeto consiste em um **blog pessoal** desenvolvido como atividade prática da **Generation Brasil**, com foco na construção de páginas web utilizando **HTML5 e CSS**, organização de código e boas práticas de desenvolvimento front-end.

O blog foi pensado para apresentar minha trajetória profissional, estudos na área de tecnologia e servir como base para evoluções futuras.

---

## 📌 Objetivo do Projeto

- Praticar a estruturação de páginas web com HTML5 semântico  
- Aplicar estilização utilizando CSS externo  
- Organizar conteúdo de forma clara e responsiva  
- Criar um projeto evolutivo, que poderá receber novas funcionalidades nas próximas etapas
